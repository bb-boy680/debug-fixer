# 根因追溯指南

逻辑缺陷与视觉缺陷的统一追溯方法论。核心思路：从异常出发，沿调用链或 DOM/CSS 继承链反向追溯，每步对照正确性假设，找到数据/样式首次偏离预期的节点。

---

## 5 步法

1. **观察症状**：确定异常位置与表现（如 `TypeError` at `applyCoupon:42`，或侧栏不显示）
2. **找直接原因**：该位置附近什么直接触发了错误
3. **向上追问**：谁调用了这段代码 / 影响了这个元素？传入参数/样式是否符合假设？
4. **继续向上**：参数/样式在上游已异常则重复步骤 3，注意跨异步、中间件、monorepo 边界
5. **定位源头**：偏差是本地产生（输入正确输出错误）→ 此即源头；仍来自上游 → 继续向上

> 静态代码无法清晰展现数据流向时，用埋点向后追踪：在可疑节点注入日志，复现后按时间线反向对比假设，直到数据首次变质。

---

## 逻辑链路

从异常函数开始，沿调用栈反向追溯：

- 函数调用、方法调用、路由/中间件链
- 导入/导出关系，跨文件/跨包调用
- 异步边界（`await`、`.then()`、回调）视为链上节点，不断裂
- 中间件、管道、拦截器必须纳入追溯

常见框架注意点：
- **Express/Koa**：按中间件加载顺序反向推导
- **React/Vue**：关注组件层级、props 传递、状态提升
- **异步任务**：记录触发源（消息队列、setTimeout），跨异步边界持续向上

---

## 视觉链路

从异常元素开始，沿 DOM 树与 CSS 继承反向追溯：

1. 检查元素自身 `computedStyles` 是否符合视觉假设
2. 自身样式正确但布局异常 → 向上检查父容器/祖先的 CSS
3. 重点关注：
   - 父容器的 `overflow`、`position`、`display`、`flex`/`grid`
   - 媒体查询是否在不同视口下覆盖样式
   - CSS 优先级：classList 和样式来源判断是否被更高优先级规则覆盖
4. 样式由 JS 动态设置 → 转入逻辑链路继续追溯

### 视觉 Bug 分类速查

| 症状 | 重点检查 |
|------|----------|
| 位置错位 | `position`、`flex`/`grid`、盒模型 |
| 点击无响应 | `z-index` 堆叠、`pointer-events`、透明遮挡层 |
| 不显示/意外显示 | `display`、`visibility`、`opacity`、条件渲染逻辑 |
| 响应式异常 | 媒体查询断点、`viewport` 设置、`rem`/`vw` 使用 |
| 弹窗被遮挡 | `z-index` 堆叠上下文、父容器 `overflow: hidden` |
| 文本截断/溢出 | `white-space`、`overflow`、`text-overflow`、容器宽度 |
| 样式不生效 | 选择器优先级冲突、`!important` 滥用、样式表加载顺序 |
| 暗色模式错误 | CSS 变量继承、`prefers-color-scheme`、`color-scheme` 属性 |
| hover/focus 无反应 | 伪类样式、选择器优先级、`pointer-events` 禁用 |
| 动画不流畅 | `transition`/`animation` 时序、重排/重绘、JS 频繁操作样式 |

### 视觉修复铁律

1. 修改根源规则，不覆写症状（不用 `!important` 强制覆盖）
2. 修复不破坏其他断点
3. 理解优先级，沿用原有选择器
4. 避免 JS 频繁操作样式，用 CSS 类名切换

---

## 源头判定

| 情况 | 判定 | 行动 |
|------|------|------|
| 入口参数/样式符合假设，但输出/渲染偏离 | 源头在**本地** | 停止追溯，修复当前节点 |
| 入口参数/样式已偏离假设 | 来自**上游** | 向上追溯调用者/父容器 |
| 自身正确但下游/子元素异常 | 检查副作用/中间件 | 向下游确认，同时检查当前节点副作用 |

### 视觉特殊判定
- 自身 CSS 规则直接导致偏差 → 源头在本地
- 受父容器样式影响（`overflow: hidden` 裁剪、`transform` 影响定位）→ 追溯父容器
- JS 动态注入且值错误 → 转入逻辑链路

---

## 偏差传播输出

确定源头后，输出完整传播路径：

**逻辑示例**：
```
【偏差传播】
getCart 返回 null → checkout 收到 cart=null → applyCoupon 访问 null.discount → TypeError
【修复】修改 getCart 确保返回空对象而非 null（源头修复）
```

**视觉示例**：
```
【偏差传播】
.sidebar-wrapper overflow:hidden + width:0 → .sidebar 被裁剪不可见 → 点击后侧栏不显示
【修复】修改 .sidebar-wrapper 在移动端媒体查询中的 width 值（源头修复）
```

---

## 与正确性假设的协同

回溯的每一步，都必须对照正确性假设：
- 高置信度假设被违背 → 修复优先级最高
- 多个低置信度假设被证伪 → 考虑触发方向自疑
- 视觉假设验证使用快照中的 `computedStyles`、`boundingClientRect` 等字段
